AI Image and Design Tools 
Some AI tools are especially helpful for visual work. 
These tools can support: 
 school presentations 
 posters 
 project visuals 
 creative assignments 
 design experimentation 
Examples include: 
 DALL·E 
 Midjourney 
 Canva AI tools 
These tools are not always necessary for every student, but they can be useful when 
students need to present ideas visually or generate design concepts. 
DALL·E and Other Image Generators 
Image generators allow students to describe an image in words and receive a visual 
result. These tools can be useful for brainstorming visual concepts, illustrating ideas, or 
designing creative materials. 
Students might use image generators to: 
 create concept art for a story 
 illustrate a presentation idea 
 design a project cover 
 visualize abstract concepts 
Students should still follow teacher expectations and school policies when using 
generated visuals in assignments.
